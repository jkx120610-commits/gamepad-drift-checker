# 手柄部件偏移检测器

一个在浏览器本地运行的手柄诊断工具，用于检测摇杆回中偏移、静止抖动和扳机未归零。手柄数据不会上传。

## 功能

- 实时显示左右摇杆轨迹、X/Y 轴读数和中心偏移。
- 3 秒静止检测，区分正常、轻微跑偏、明显跑偏和信号抖动。
- 检测左右扳机在未按下时的静止值。
- 轨迹支持 1x、2x、4x、8x 放大。
- 显示全部按键状态和扳机行程。
- 支持 Xbox、PlayStation、Switch 等使用标准 Gamepad API 映射的手柄。

## 使用

1. 使用最新版 Chrome、Edge 或 Firefox 打开 `index.html`。
2. 连接手柄并按下任意按键，让浏览器识别设备。
3. 松开双手，不要触碰摇杆和扳机。
4. 点击“开始静止检测”，保持手柄静止 3 秒。

浏览器必须支持 Gamepad API。部分浏览器要求页面获得焦点后才能持续读取手柄输入。

## 判定参考

| 部件 | 正常 | 轻微偏移 | 明显偏移 |
| --- | --- | --- | --- |
| 摇杆中心偏移 | `< 0.07` | `0.07 - 0.20` | `>= 0.20` |
| 摇杆静止噪声 | `< 0.035` | `>= 0.035` | - |
| 扳机静止值 | `< 0.08` | `0.08 - 0.30` | `>= 0.30` |

不同游戏和手柄的死区设置不同。检测结果适合用于横向比较和故障排查，不替代厂商校准工具。

## Windows 便携版

发布包中的 `手柄部件偏移检测器.exe` 会调用系统默认浏览器打开本地检测页，不需要安装。Windows 便携版由 GitHub Releases 提供。

## 开发

应用是一个不依赖构建工具的静态 HTML 文件。修改 `index.html` 后刷新浏览器即可。
